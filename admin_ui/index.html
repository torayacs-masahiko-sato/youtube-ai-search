管理画面ログイン

パスワードを忘れた場合は、他の管理者に再設定を依頼してください

認証アプリ（Google Authenticator / Microsoft Authenticator など）に表示されている6桁のコードを入力してください。

セキュリティ強化のため、認証アプリの登録が必要です（初回のみ）。
① スマホで認証アプリを開き、「＋」から下のQRコードを読み取る
② アプリに表示された6桁のコードを入力する

QRコードが読み取れない場合は、アプリの「キーを入力」から次の文字列を入力してください。

リカバリーコードを保管してください。スマホを紛失・機種変更して認証アプリが使えなくなったときに、1つにつき1回だけログインに使えます。

⚠ この画面を閉じると二度と表示されません。印刷するか、パスワード管理ツール等の安全な場所に保存してください。
